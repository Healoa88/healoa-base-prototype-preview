# 夏威夷 · 火山 — 沉浸场景样张（SAMPLE，不要合并）

这是一个独立页面，**没有改动**主 demo 的 `index.html`。
流程：首页 → 感受签到（小海龟 Honu 陪你选）→ 推荐 → 门口 → 推开门 → 熔岩小树（2.5D 视差）→ 放入你的狗狗或自己（照片在手机里抠图）→ 挑装扮 → 留一句 → 竖版小视频 + 明信片（带二维码）→ 养成 / 积分 / 回访。

- 本地运行：在仓库根目录执行 `python3 -m http.server 8765`，然后打开 `http://127.0.0.1:8765/immersive-hawaii/`
- 测试：`npm run test:immersive`（主 demo 的测试照旧用 `npm run test:scene-seed`）
- 文档：`docs/RESEARCH.md` · `docs/SOURCES.md` · `docs/HOMEPAGE_COPY.md`（首页文案 + 签到推荐规则表）· `docs/POINTS_REFERRAL_SPEC.md`
- 没有后端，所有数据只存在这台设备上（localStorage）。换设备后数据能不能跟过去：**没做 / UNKNOWN**。

## 2026-09-27 修正（grok/hawaii-sample-fixes）
- **抠图干净**：自动抠图之后，再从已抠掉的区域和照片边缘做一次「同色填充」，跟背景同颜色、又连着背景的残留像素一起去掉；零星小碎块去掉；边缘还带背景色的 1–2 像素淡出（没有白边）。被主体包住的同色细节（比如眼睛高光）不会被误删。代码：`js/cutout.js`（纯函数，有单元测试）。
- **亮度跟背景一致**：按 TA 所在位置周围的背景平均亮度和颜色，算一个增益（亮度 75% 靠拢、颜色 35% 靠拢，有上下限），再套上跟场景完全一样的调色（暖调 / 清晨）。
- **所见即所得**：第 2、3 步里，底部菜单上方的画面就是明信片的整块上层（1080×1380 同一比例、同一取景、不晃动），第 3 步还实时显示明信片上的那句话；拖动只能拖在这个框里。
- **喇叭 = 循环播放主题音乐**：占位路径 `assets/audio/PLACEHOLDER-hawaii-theme-cindy-will-supply.mp3`（等 Cindy 的 MP3，见 `assets/audio/README.md`）；文件不在时只提示，不报错。
- **分享**：用系统分享面板直接带文件（`navigator.share({files})`，视频在前、明信片在后；只收一个文件的就只给当前那个）；不能分享文件的设备直接保存文件。新增「存视频文件」按钮：下载真正的 .mp4（浏览器能录 mp4 时）或 .webm 文件；音乐文件在、声音开着时，会把音乐录进视频。
